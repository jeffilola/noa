# Demo note: M7 learning records

Date: 2026-06-11

## What shipped

- Compliance records are persisted as first-class records tied to a user and organization.
- Dev bootstrap seeds demo training and certification records for the configured Clerk user.
- The org member access decision panel now reads training and certification status from the API instead of hard-coded stubs.
- The holder Training & certs route at `/user/compliance` shows the same seeded learning records for the signed-in holder.

## Demo path

1. Run `pnpm qa:prepare`.
2. Start the stack with `pnpm qa:servers`.
3. Sign in with `DEMO_CLERK_USER_ID`.
4. Open `/org/users`.
5. Open a member access view.
6. Confirm the access decision panel shows real seeded training and certification records.
7. Switch to the Identity Holder dashboard, open **Training & certs**, and confirm `/user/compliance` lists the same training and certification rows.
