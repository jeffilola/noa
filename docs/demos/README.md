## How to add a demo note

1. Copy [TEMPLATE.md](./TEMPLATE.md) to `YYYY-MM-DD.md` (demo date).
2. Fill in what shipped, what broke, and what's next.
3. Link merged PRs and closed issues.
4. Add a row to the index above.

Keep each note to **~10 lines** — enough for future-you to remember context.
