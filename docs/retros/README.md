## How to run a retro (15 min)

1. Copy [TEMPLATE.md](./TEMPLATE.md) to `YYYY-MM-DD.md`.
2. Answer: **Keep** / **Stop** / **Try** (one bullet each minimum).
3. Turn **Try** items into GitHub issues if actionable.
4. Add a row to the index above.
