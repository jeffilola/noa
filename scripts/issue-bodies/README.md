```powershell
gh issue edit 36 --body-file scripts/issue-bodies/36-account-deletion-flow.md
gh issue edit 37 --body-file scripts/issue-bodies/37-security-nav-consolidation.md
```

New issues should include **Test procedures** via the GitHub issue templates.
